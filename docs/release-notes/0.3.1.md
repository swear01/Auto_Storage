Auto Storage 0.3.1 makes the client recipe viewer optional: install **either
EMI or JEI**. EMI is preferred when both are present. Dedicated servers still
do not need a recipe viewer.

With JEI only (for example All the Mods 10), Crafting Terminal diagrams, Search
Sync, and JEI recipe transfer use JEI's public runtime. When JEI runtime becomes
unavailable after logout or reload, the client falls back to the native diagram
path instead of keeping a stale runtime.

This is a non-breaking patch on the 0.3.x identity line. Keep only one Auto
Storage jar in an instance.
