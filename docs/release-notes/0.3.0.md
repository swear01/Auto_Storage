> **Breaking identity change:** Auto Storage 0.3.0 does not migrate or alias
> 0.2.x worlds, registries, configs, commands, addon IDs, or saved data.

Remove every 0.2.x jar before installing 0.3.0, do not mix both versions in one
instance, and start a new world.

The canonical technical identity is now `auto_storage`, the Java package is
`com.swear.autostorage`, and the release artifact is
`auto_storage-0.3.0.jar`.

For addon developers, 0.3.0 adds the modular public SDK and the downloadable
Auto Storage Compat Kit. The Kit audits a representative target artifact,
generates explicit RED integration scaffolds, and runs declared compatibility
gates; its first bundled dogfood integration supports deterministic AE2
Inscriber recipes when AE2 is installed.
